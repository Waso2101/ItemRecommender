#     Stufe/tier:  2 = Kern        -> goldener Rahmen + Stern / gold frame + star
#                  1 = gut         -> heller Rahmen          / light frame
#                  0 = neutral     -> nichts (auch: Default für diesen Char aufheben)
#                 -1 = eher nicht  -> oranger Rahmen + X     / orange frame + X
#                 -2 = nicht bauen -> roter Rahmen + X       / red frame + X
#
#  [Synergy]  (Hast du das linke Item, wird das rechte bewertet)
#  A > B      Synergie: B +1 Stufe, türkiser Punkt     (A <> B = beide Richtungen)
#  A !> B     Anti-Synergie: B wird "eher nicht" (orange)
#  A !!> B    Anti-Synergie: B wird "nicht bauen" (rot)

#     Mehrere "Path:"-Zeilen = mehrere Seiten. Ist eine Seite voll, kommt die nächste.
